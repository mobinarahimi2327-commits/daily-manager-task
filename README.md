# daily-manager-task
#  پروژه مدیریت وظایف حرفه‌ای (Python Task Manager)

یک برنامه دسکتاپ حرفه‌ای برای مدیریت وظایف روزانه با استفاده از **Python**, **Tkinter**, **SQLite** و **Plyer**.  
این برنامه به شما کمک می‌کند تا وظایف خود را ثبت، ویرایش، حذف و فیلتر کنید و برای کارهای امروز اعلان (Notification) دریافت نمایید.

---
##  ویژگی‌ها

-  افزودن وظیفه جدید  
-  ویرایش وظیفه انتخابی  
-  علامت‌گذاری وظیفه به عنوان انجام‌شده  
-  حذف وظایف انتخاب‌شده  
-  فیلتر وظایف (همه / انجام‌شده / انجام‌نشده)  
-  اعلان خودکار وظایف امروز با `plyer`  
-  ذخیره داده‌ها در پایگاه داده SQLite  
-  رابط گرافیکی مدرن با طراحی تیره و رنگ‌بندی جذاب  

---

##  نصب و اجرا

###  نصب وابستگی‌ها

```bash
pip install plyer
 اجرای برنامه

کد را در فایلی به نام task_manager.py ذخیره کرده و اجرا کنید:

python task_manager.py


در اولین اجرا، پایگاه داده به‌صورت خودکار ساخته می‌شود (tasks.db).
 ساختار پایگاه داده (SQLite)
ستون	نوع داده	توضیح
id	INTEGER	شناسه خودکار
title	TEXT	عنوان وظیفه
due_date	TEXT	تاریخ انجام (YYYY-MM-DD)
done	INTEGER	وضعیت (۰ = انجام‌نشده، ۱ = انجام‌شده)
 ساختار کلی کد
🔹 ۱. تنظیمات پایگاه داده

در ابتدای برنامه، اگر فایل tasks.db وجود نداشته باشد ساخته می‌شود:

conn = sqlite3.connect("tasks.db")
cur = conn.cursor()
cur.execute("""
CREATE TABLE IF NOT EXISTS tasks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    due_date TEXT,
    done INTEGER DEFAULT 0
)
""")

🔹 ۲. توابع اصلی
 refresh()

به‌روزرسانی جدول نمایش وظایف با توجه به فیلتر انتخابی (همه، انجام‌شده، انجام‌نشده).
وظایف با رنگ‌بندی مشخص نمایش داده می‌شوند.

 add_task()

افزودن وظیفه جدید با عنوان و تاریخ مشخص.

 complete_task()

علامت‌گذاری وظیفه انتخابی به عنوان انجام‌شده.

 edit_task()

ویرایش عنوان و تاریخ انجام وظیفه انتخابی.

 delete_task()

حذف وظایف انتخاب‌شده از لیست و دیتابیس.

 notify_today_tasks()

نمایش اعلان دسکتاپ برای کارهایی که تاریخ انجام آن‌ها برابر تاریخ امروز است.

🔹 ۳. رابط کاربری (GUI)

برنامه با Tkinter طراحی شده و شامل بخش‌های زیر است:

بخش	توضیح
 فرم ورودی	محل وارد کردن عنوان و تاریخ وظیفه
 دکمه‌ها	افزودن، ویرایش، انجام‌شده، حذف
 جدول نمایش	لیست وظایف با رنگ‌بندی و وضعیت
 فیلتر پایین صفحه	فیلتر بر اساس وضعیت (همه / انجام‌نشده / انجام‌شده)
 طراحی گرافیکی

پس‌زمینه تیره و مدرن

رنگ سبز برای وظایف انجام‌شده

رنگ نارنجی برای وظایف در انتظار

فونت فارسی خوانا (مثل Vazirmatn)

دکمه‌های رنگی با آیکون برای درک سریع عملکرد

 کتابخانه‌های مورد استفاده
